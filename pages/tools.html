Tools & Setup Guide

Before you start learning, you need the right tools. Here's everything you need to install and set up your development environment — with download links and quick guides.

01

Code Editors

Start Here

A code editor is where you write your code. Pick one and stick with it.

Visual Studio Code

Recommended

The most popular free code editor. Supports every language, has thousands of extensions, and runs on Windows, Mac, and Linux.

Python JavaScript Web Dev All Languages
⬇ Download VS Code

PyCharm

Python Only

The best IDE specifically for Python. Has powerful debugging, code completion, and project management tools built-in.

Python Data Science AI/ML
⬇ Download PyCharm

IntelliJ IDEA

Java / Kotlin

The industry-standard IDE for Java development. Powerful smart code completion and analysis tools for enterprise development.

Java Kotlin Spring Boot
⬇ Download IntelliJ
02

Runtime Environments

Required

Runtimes let your computer actually run code. Install the ones for the languages you're learning.

Python

Recommended

The most beginner-friendly programming language. Required for Python, Data Engineering, AI/ML, and Data Analytics tracks.

Python AI/ML Data Eng Analytics
⬇ Download Python

Node.js

JavaScript

Lets you run JavaScript outside the browser. Required for backend development with Node.js and Express.

JavaScript Web Dev Backend
⬇ Download Node.js

Java JDK

Java

Java Development Kit — required to write and run Java programs. Download JDK 17 LTS for the latest stable version.

Java Spring Boot Android
⬇ Download Java JDK
03

Version Control

Must Have

Version control lets you track changes in your code and collaborate with others. Every developer needs Git.

Git

Recommended

The industry standard for version control. Track changes, create branches, and collaborate on any project. Free and open source.

All Languages Collaboration Open Source
⬇ Download Git

GitHub Desktop

GUI for Git

A visual interface for Git. Great for beginners who prefer not to use the command line. Syncs directly with GitHub.

Beginner Friendly GitHub GUI
⬇ Download GitHub Desktop

GitHub Account

Free

Host your code online, collaborate with others, and build your developer portfolio. Sign up for a free account at github.com.

Portfolio Collaboration Free
⬇ Create GitHub Account
04

Package Managers

Essential

Package managers let you install libraries and tools with a single command. Installed automatically with Python and Node.js.

pip

Python

Python's built-in package manager. Use it to install libraries like pandas, numpy, django, and more. Comes with Python automatically.

Python Built-in
pip install package-name

npm

JavaScript

Node Package Manager — comes with Node.js. Install JavaScript libraries and frameworks like Express, React, and more.

JavaScript Node.js Built-in
npm install package-name

Virtual Environment

Python

Isolate Python packages per project. Best practice for every Python project to avoid version conflicts between projects.

Python Best Practice
python -m venv env
05

Database Tools

Data Storage

Databases store your app's data. Different tools are used for different purposes.

MySQL

Recommended

The most popular open-source relational database. Great for learning SQL and building web applications with PHP or Python.

SQL PHP Web Dev
⬇ Download MySQL

PostgreSQL

Advanced SQL

A powerful open-source database with advanced features. Preferred for data engineering, analytics, and production applications.

SQL Data Eng Analytics
⬇ Download PostgreSQL

SQLite

Beginner

A lightweight database that stores data in a single file. Perfect for learning SQL basics and small projects. No installation required.

SQL Beginner Built-in
⬇ Download SQLite
